description: Non-overlapping monetary sections in the same live Telegram dashboard.

Keep a separate section for public sports trades worth more than $5,000 and less than $10,000. Do not mix its trades or totals with the existing $10,000-and-above section. Exactly $5,000 is excluded; exactly $10,000 belongs only to the existing upper section.

**Why:** The user requested an additional lower-value section specifically so it would not mix with the existing one. The shared $10,000 boundary stays in the original inclusive section to avoid duplicates.

**How to apply:** Use the selected monetary section consistently for sport/game/market lists, trade counts, graph points, captions, and filters. The same market may appear in both sections, but each graph must use only its section's trades. Preserve the user's approved one-message dashboard and persist the active section through navigation and restarts.
